Read with care

  • This is the best case on fading. {{ rcFade }}
  • A second turn is assumed to help as much as the first. {{ rcTwice }}
  • Each round serves students who have not had a turn. {{ rcRand }}
  • If the same students signed up every round, {{ rcRep }}
  • The rounds are a thought experiment on one group of students. Real students move on to the next grade, so this shows the size of the task, not a schedule.
  • Averages follow the same students. Counted across all students, the count can run about a round longer, and the gap widens slightly while a round is under way.
  • The presets are hopeful. The 0.155 SD average for large tutoring programs is not statistically different from zero. The 18.7% sign-up rate was measured among students offered tutoring and is applied here as if every student were offered.
